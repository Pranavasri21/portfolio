Smart Home Smoke Detection System (IoT)

An IoT-based smart home safety system that detects smoke, fire, gas leakage and motion. When danger is detected, the system activates alarms using buzzer and LED alerts and can send SMS notifications using GSM module.

Hardware Used:

  • Arduino Uno
  • MQ2 Smoke Sensor
  • Gas Sensor
  • Flame Sensor
  • PIR Motion Sensor
  • Buzzer and LEDs
  • SIM800 GSM Module

Software & Tools: Arduino IDE, Embedded C/C++

Outcome: Successfully detected smoke and fire conditions and triggered emergency alerts to improve home safety.

SheShield Sentinel – ML Based Women Safety Navigation System

SheShield Sentinel is a machine learning-based women safety navigation system that helps users find safer travel routes.

Users can create an account using login/signup, enter source and destination locations, and compare safer routes with faster routes using calculated safety risk scores.

The system integrates with Google Maps for real-time navigation assistance.

In emergency situations, users can press the "I'm in Danger" button, which shares the user's live location with trusted contacts for immediate help.

Features:

  • Login and Signup Authentication
  • Source and Destination Route Selection
  • Safer Route vs Faster Route Comparison
  • Safety Risk Score Prediction
  • Google Maps Navigation Integration
  • Emergency Alert with Live Location Sharing

Technologies Used: Python, HTML, CSS, JavaScript, Machine Learning, Google Maps API

Outcome: Developed a safety-focused navigation prototype aimed at improving women’s safety during travel using smart route analysis and emergency support.
