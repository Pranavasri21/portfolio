Smart Home Smoke Detection System (IoT)

An IoT-based smart home safety system that detects smoke, fire, gas leakage, and motion. When danger is detected, the system activates alarms using a buzzer and LED alerts and sends SMS notifications through a GSM module.

Hardware Used:

  • Arduino Uno
  • MQ2 Smoke Sensor
  • Gas Sensor
  • Flame Sensor
  • PIR Motion Sensor
  • Buzzer and LEDs
  • SIM800 GSM Module

Software & Tools: Arduino IDE, Embedded C/C++

Outcome: Successfully detected smoke and fire conditions, triggered emergency alerts, and improved home safety through real-time monitoring.

SheShield Sentinel – ML-Based Women Safety Navigation System

SheShield Sentinel is a machine learning-based women safety navigation system that helps users identify safer travel routes based on crime data analysis and route safety prediction.

Users can create an account, log in securely, enter source and destination locations, and compare safer routes with faster routes using calculated safety risk scores.

The system integrates with Google Maps for real-time navigation assistance and provides intelligent route recommendations.

During emergencies, users can press the "I'm in Danger" button to instantly share their live location with trusted contacts for immediate assistance.

Features:

  • Login & Signup Authentication
  • Source and Destination Route Selection
  • Safer Route vs Faster Route Comparison
  • Machine Learning-Based Safety Risk Prediction
  • Google Maps Navigation Integration
  • Emergency Alert with Live Location Sharing

Technologies Used: Python, HTML, CSS, JavaScript, Machine Learning, Google Maps API

Outcome: Developed an intelligent navigation prototype that promotes safer travel by combining machine learning, smart route analysis, and emergency response features.
